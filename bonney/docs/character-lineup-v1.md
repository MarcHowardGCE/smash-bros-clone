# Six-character lineup review v1

Deliverables: assets/character-lineup-v1/
- Six transparent 32x32 idle PNGs, named by outfit and age.
- bonney-six-idles.png: 96x64 sheet; columns baby, teenage, adult; rows Egghead, Captain.
- bonney-lineup-review.png: labeled enlarged and native-size comparison.
- manifest.json: frame rectangles and shared anchor.

Generated by scripts/generate-character-lineup.ps1 using integer-coordinate pixel shapes and a limited palette. It imports drawing helpers from the earlier pixel-study generator without executing its exports. Run with Windows PowerShell/System.Drawing.

References: assets/references/egghead-age-lineup.png and pirate-captain-age-lineup.png.
Egghead cues: purple outfit, headset antenna, oversized boots.
Captain cues: green hat, brown jacket, orange waistband, mismatched stockings.
Baby and teenage outfits use fully covering adventure clothing.
Age varies through silhouette height and body proportions; all ages share a 32x32 cell and baseline at opaque row 30. Art height must not alter movement or grant different abilities.

Checks completed: all six unique; 32x32 dimensions; alpha only 0 or 255; nonempty; common opaque baseline y=30. Review board visually inspected for clipping, labels, and scale. No gameplay or animations implemented by this milestone. Collision geometry remains to be defined independently of visible sprite bounds.

These are first-pass idle designs, with deliberate simplification from the illustration references. They remain subject to user visual review. Next: flight/cannonball storyboard and updated harbor HUD study, followed by animation refinement and a playable test screen.

Confirmed gameplay: one equipped power-up; another pickup replaces it. Adult -> teenage -> baby -> death. Ordinary movement/actions identical at every age. Egghead flight lasts 5 seconds; ability cooldown is 5 seconds after ability end. Cannonball duration and damage values remain open.
